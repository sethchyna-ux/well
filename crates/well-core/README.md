# 🧱 well-core: Shared Primitives & Foundation

The `well-core` crate defines the fundamental types, cell geometries, grid representations, and coordinate systems shared across all subsystems in the Well architecture.

---

## Contents

* **Grid Geometry**: Window and cell dimension abstractions (`GridSize`, `CellDimensions`).
* **Color Representation**: Compact packed 12-bit RGB color formats and RGBA utilities.
* **Typographic Definitions**: Cell attribute flags (bold, italic, underline, strikethrough, inverse).
